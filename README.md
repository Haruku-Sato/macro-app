# マウスマクロ

マウス操作（移動・クリック・スクロール）を記録して再生できる、シンプルな GUI マクロツールです。

## 機能

- マウス操作の**記録・再生**
- **繰り返し回数**の指定（1〜999回）
- **再生速度**の変更（0.5x / 1.0x / 1.5x / 2.0x）
- マクロの **JSON 保存・読み込み**
- グローバルホットキーによる操作（アプリ外からでも使用可能）

## ホットキー

| キー | 動作 |
|------|------|
| `F9` | 記録開始 / 停止 |
| `F10` | 再生開始 / 停止 |

## 必要環境

- Python 3.x
- pynput

## インストール

```bash
pip install -r requirements.txt
```

## 起動方法

```bash
python main.py
```

## 使い方

1. **記録開始** ボタン（または `F9`）を押してマウス操作を記録する
2. **記録停止** ボタン（または `F9`）を押して記録を終了する
3. 繰り返し回数・速度を設定する
4. **再生** ボタン（または `F10`）を押して操作を再生する
5. 必要に応じて **保存** ボタンで JSON ファイルに書き出す

保存した JSON ファイルは **読み込み** ボタンで再利用できます。

## ファイル構成

```
macro_app/
├── main.py          # GUI・アプリ本体
├── recorder.py      # マウスイベント記録
├── player.py        # マクロ再生
└── requirements.txt # 依存パッケージ
```

## マクロファイルのフォーマット（JSON）

```json
[
  { "time": 0.0,  "type": "move",   "x": 100, "y": 200 },
  { "time": 0.5,  "type": "click",  "x": 100, "y": 200, "button": "left", "pressed": true },
  { "time": 0.51, "type": "click",  "x": 100, "y": 200, "button": "left", "pressed": false },
  { "time": 1.0,  "type": "scroll", "x": 100, "y": 200, "dx": 0, "dy": -3 }
]
```

- `time`: 記録開始からの経過秒数
- `type`: `move` / `click` / `scroll`
- `button`: `left` / `right`（click のみ）
- `pressed`: `true` = 押下、`false` = 離す（click のみ）
